LoL Tracker

이 서비스는

LoL Tracker는 리그 오브 레전드 전적 검색에 챔프 셀렉트 단계의 픽 추천을 더한 비공식 통계 서비스입니다. 소환사 전적, 매치 분석, 챔피언 통계 같은 기본 기능은 물론, 우리팀과 적팀의 픽 정보를 입력하면 자기 라인에 적합한 챔프를 카운터·시너지·메타·마스터리 4개 축으로 점수화해 추천합니다. 게임 시작 전 1분이 가장 중요한 LoL의 특성을 반영해, '검색이 끝난 뒤'가 아닌 '검색이 필요한 그 순간'에 가치를 주는 것을 목표로 만들었습니다.

주요 기능

  • 소환사 전적 검색 — Riot ID 기준 (이름#태그)
  • 매치 상세 분석 — 스코어보드, 빌드, 데미지 분포, 골드/경험치 그래프
  • 챔피언 티어표 — 라인·티어·패치별 승률·픽률·밴률
  • 챔피언 상세 — 빌드, 룬, 스킬 빌드 순서, 카운터 정보
  • 라이브 게임 — 진행 중인 게임의 양 팀 정보와 승률 예측
  • 픽 추천 (BETA) — 챔프 셀렉트 단계의 픽 추천
  • 멀티서치 — 5명까지 동시 검색
  • 랭킹 — 서버별 챌린저·그랜드마스터·마스터 리더보드

데이터 출처

모든 게임 데이터는 Riot Games API를 통해 수집되며, 챔피언·아이템·룬 이미지는 Data Dragon CDN에서 직접 제공됩니다. 챔피언 티어와 픽 추천 점수는 자체 알고리즘으로 일정 주기마다 집계됩니다.
